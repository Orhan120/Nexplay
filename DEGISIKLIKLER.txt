NEXPLAY başlangıç paketi değişiklikleri
1) nexplay-original.html: yüklenen orijinal dosyanın birebir kopyası.
2) www/index.html: orijinal uygulama kodu + yalnızca adsDemo=false ve bridge script etiketi.
3) www/nexplay-capacitor.js: native rewarded-ad köprüsü.
4) package.json / capacitor.config.ts: Capacitor proje yapılandırması.
5) native-ads/PLUGIN_CONTRACT.md: gerçek LevelPlay native plugin gereksinimleri.
6) README_TR.md: kurulum ve yayın adımları.

Not: Android/iOS native platform klasörleri henüz üretilmedi. Bunlar npm install
sonrası npx cap add android / npx cap add ios komutlarıyla oluşturulur.
Gerçek LevelPlay plugin kodu ve dashboard anahtarları olmadan gerçek reklam
gösterimi/gelir elde etme mümkün değildir.
